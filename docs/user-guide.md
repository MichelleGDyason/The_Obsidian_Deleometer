## Installation

1. Open Obsidian and go to Settings
2. Click on "Community Plugins" and then "Browse"
3. Search for "Deleometer"
4. Click "Install" and then "Enable"
5. Configure your API key in the Deleometer settings

## Getting Started

After installation, you'll need to:

1. Set up your OpenAI API key in the Deleometer settings
2. Choose which features you want to enable
3. Start journaling in your daily notes or any markdown file

## Core Features

### Journal Analysis

The Deleometer can analyze your journal entries to provide psychological insights:

1. Write your journal entry in a daily note or any markdown file
2. Use the command palette (Ctrl/Cmd+P) and search for "Deleometer: Analyze Current Note"
3. View the analysis results in the modal that appears

The analysis includes:
- Emotional patterns and themes
- Psychological insights based on your chosen frameworks
- Visualizations of emotional states
- Personalized recommendations

### Analysis Scope

The Analysis Scope feature allows you to analyze content beyond daily notes:

1. Use the command palette and search for "Deleometer: Analyze Content"
2. Select the type of content you want to analyze:
   - Current Note
   - File
   - Folder
   - Multiple Files
   - Multiple Folders
   - Vault
3. Configure analysis options and click "Analyze"

For more details, see the [Analysis Scope documentation](analysis-scope.md).

### Journaling Prompts

Journaling Prompts provide inspiration for your writing:

1. Use the command palette and search for "Deleometer: Open Journaling Prompts"
2. Browse through the available prompts
3. Filter prompts by category using the dropdown menu
4. Click on a prompt to copy it to your clipboard
5. Paste the prompt into your journal entry and start writing

For more details, see the [Journaling Prompts documentation](journaling-prompts.md).

### Theoretical Frameworks

The Deleometer offers multiple psychological and philosophical frameworks for analysis:

- **Freudian**: Classic psychoanalytic approach focusing on unconscious drives, defense mechanisms, and psychosexual development
- **Lacanian**: Focuses on language, symbolism, and the structure of the unconscious
- **Deleuzian**: Schizoanalytic approach examining desire, assemblages, and lines of flight
- **Irigarayian**: Feminist psychoanalytic perspective on sexual difference and feminine subjectivity

You can enable or disable these frameworks in the settings.

## Advanced Features

### User Profiling

User Profiling builds a psychological profile based on your writing patterns:

1. Enable User Profiling in the settings
2. Continue journaling regularly
3. The Deleometer will learn from your writing and provide increasingly personalized insights
4. View your profile by using the command "Deleometer: View User Profile"

### Adaptive Learning

Adaptive Learning allows the Deleometer to improve its analysis over time:

1. Enable Adaptive Learning in the settings
2. Provide feedback on analysis results when prompted
3. The system will adjust its approach based on your feedback

### Next Steps Recommendations

Next Steps Recommendations provide personalized suggestions for growth:

1. Enable Next Steps Recommendations in the settings
2. After each analysis, you'll receive tailored recommendations
3. Categories include emotional, cognitive, behavioral, relational, spiritual, and creative

## Settings

The Deleometer offers extensive customization options:

- **API Settings**: Configure your OpenAI API key and model
- **Feature Toggles**: Enable or disable specific features
- **Analysis Options**: Set detail level and theoretical frameworks
- **Integration Settings**: Configure daily notes integration
- **Advanced Settings**: Customize technical aspects of the plugin

## Troubleshooting

Common issues and solutions:

- **API errors**: Ensure your OpenAI API key is valid and has sufficient credits
- **Slow analysis**: For large content sets, try reducing the maximum number of entries
- **Missing features**: Make sure the feature is enabled in settings
- **Plugin not loading**: Try restarting Obsidian

## FAQ

**Q: Is my data private?**
A: Yes, your journal entries are processed locally and sent only to the OpenAI API. No data is stored on our servers.

**Q: How much does it cost to use?**
A: The Deleometer plugin is free, but you need an OpenAI API key which has its own pricing.

**Q: Can I use the Deleometer offline?**
A: No, an internet connection is required to use the OpenAI API.

**Q: How accurate is the analysis?**
A: The analysis is based on advanced AI models but should be viewed as a tool for reflection rather than definitive psychological assessment.

**Q: Can I export my analysis results?**
A: Yes, you can export analysis results to markdown files for future reference.
