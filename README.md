# Deleometer: AI-Powered Journal Analysis & Artistic Exploration

Deleometer is an Obsidian plugin that provides deep analysis of journal entries, artistic content, and other media using multiple theoretical frameworks. It helps you gain insights into your thoughts, emotions, and creative expressions through the lens of various psychological and philosophical perspectives.

## Features

### Core Features

- **Journal Analysis**: Analyze your journal entries for emotional patterns, psychological insights, and personal growth opportunities
- **Artistic Analysis**: Analyze images, audio, film, and text using multiple theoretical frameworks
- **Comparative Analysis**: Compare different media types and analyze them using any combination of frameworks
- **Personalized Recommendations**: Get tailored suggestions for personal growth based on your journal entries
- **Security Features**: Protect your sensitive journal entries with encryption and local processing

### Theoretical Frameworks

Deleometer supports analysis through multiple theoretical lenses:

- **Tacktical Methodology** (Bufardeci)
- **Freudian Psychoanalysis**
- **Lacanian Psychoanalysis**
- **Deleuzian Schizoanalysis**
- **Irigarayian Feminist Theory**
- **Jungian Analytical Psychology**
- **Attachment Theory**
- **Positive Psychology**
- **Narrative Psychology**
- **Phenomenology**
- **Existentialism**
- **Feminist Theory**
- **Critical Theory**
- **Posthumanism**
- **Buddhist Philosophy**
- And many more...

### Media Support

- **Text**: Journal entries, notes, and other text documents
- **Images**: JPG, PNG, GIF, and other image formats
- **Audio**: MP3, WAV, and other audio formats
- **Film**: MP4, MOV, and other video formats

## Installation

### Quick Installation

1. Download the `the-deleometer-obsidian-ai-deepself-discovery-journaling.zip` file from this repository
2. Extract the zip file
3. Copy the `the-deleometer-obsidian-ai-deepself-discovery-journaling` folder to your vault's `.obsidian/plugins/` directory
4. Make sure the folder structure looks like this:
   ```
   .obsidian/plugins/the-deleometer-obsidian-ai-deepself-discovery-journaling/
   ├── manifest.json
   ├── styles.css
   ├── README.md
   └── build/
       └── main.js
   ```
5. Restart Obsidian
6. Enable the plugin in Settings > Community plugins

For more detailed instructions, see [INSTALLATION.md](docs/INSTALLATION.md).

### Troubleshooting

If the plugin doesn't appear in Obsidian:

1. Make sure you've copied the entire folder to the correct location
2. Check that the folder name matches the plugin ID in the manifest.json file
3. Verify that your Obsidian version is at least 0.15.0
4. Try restarting Obsidian
5. Check the developer console (Ctrl+Shift+I or Cmd+Option+I) for any error messages

## Usage

### Analyzing Journal Entries

1. Open a journal entry in Obsidian
2. Open the Command Palette (Ctrl/Cmd+P)
3. Search for "Deleometer: Analyze Journal Entry"
4. View the analysis results in the modal that appears

### Analyzing Artistic Content

1. Add an image, audio, or film file to your vault
2. Open the Command Palette (Ctrl/Cmd+P)
3. Search for "Deleometer: Analyze Artistic Content"
4. Select the file you want to analyze
5. Choose which theoretical frameworks to apply
6. View the analysis results

### Comparative Analysis

1. Open the Command Palette (Ctrl/Cmd+P)
2. Search for "Deleometer: Comparative Analysis"
3. Select multiple files to compare (can be different media types)
4. Choose which theoretical frameworks to apply
5. View the comparative analysis results
