# Deleometer Stub Files

This directory contains stub files for the Deleometer plugin. These files provide minimal implementations of the classes and interfaces required by the main.ts file, allowing it to compile without errors.

## What are Stub Files?

Stub files are placeholder implementations that satisfy import requirements without implementing the full functionality. They're useful when you want to make code compile without implementing all the features.

## How to Use These Stub Files

To use these stub files, you can either:

1. Copy them to the main src directory (replacing any existing files with the same name)
2. Import them directly from the stubs directory by modifying the import paths in main.ts

## Stub File Structure

Each stub file provides:

- The necessary class or interface definitions
- Empty or minimal implementations of methods
- Console.log statements to indicate when methods are called but not implemented

## Replacing Stubs with Real Implementations

As you develop the plugin, you can gradually replace these stub files with real implementations. The stub files serve as a starting point and documentation of the expected interfaces.
