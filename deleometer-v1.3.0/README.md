# Deleometer: Theoretical Analysis for Obsidian

Deleometer is an Obsidian plugin that provides comprehensive theoretical analysis for journal entries, artistic content, and other media using multiple frameworks from psychology, philosophy, and critical theory.

## Features

### Unified Theoretical Analysis

Analyze any content in your vault through multiple theoretical lenses:

- **Text Analysis**: Journal entries, notes, creative writing
- **Image Analysis**: Photographs, artwork, diagrams
- **Audio Analysis**: Music, spoken word, field recordings
- **Film Analysis**: Videos, animations, film clips

### Multiple Theoretical Frameworks

Choose from a wide range of frameworks:

- **Tacktical Methodology** (Bufardeci)
- **Freudian Psychoanalysis**
- **Lacanian Psychoanalysis**
- **Deleuzian Schizoanalysis**
- **Irigarayian Feminist Theory**
- **Jungian Analytical Psychology**
- **Attachment Theory**
- **Positive Psychology**
- **Narrative Psychology**
- **Phenomenology**
- **Existential Psychology**
- **Feminist Theory**
- **Critical Theory**
- **Posthumanism**
- **Buddhist Psychology**
- **Nietzschean Philosophy**
- **Gestalt Psychology**
- **Transpersonal Psychology**
- **Cognitive Behavioral Therapy**
- **Hermeneutics**
- **Stoicism**
- **Psychiatry**

### Customizable Settings

- Enable/disable specific frameworks
- Adjust analysis depth
- Toggle journaling prompts

## Installation

1. Download the `deleometer` folder from this package
2. Copy the folder to your Obsidian vault's `.obsidian/plugins/` directory
3. Restart Obsidian
4. Enable the Deleometer plugin in Settings → Community plugins

## Usage

### Analyzing Content

1. Open any file in your vault (or select a file in the analysis modal)
2. Click the brain icon in the left sidebar, or use the Command Palette (Ctrl/Cmd+P) to run "Deleometer: Theoretical Analysis"
3. Select which theoretical frameworks to apply
4. View the analysis results

### Configuring Settings

1. Go to Settings → Deleometer
2. Enable or disable specific theoretical frameworks
3. Adjust analysis depth (Brief, Standard, Detailed)
4. Toggle journaling prompts
