# Deleometer Plugin for Obsidian

Deleometer is an AI-powered journal analysis and artistic exploration plugin for Obsidian. It provides deep analysis of journal entries, artistic content, and other media using multiple theoretical frameworks.

## Features

- **Journal Analysis**: Analyze your journal entries using multiple theoretical frameworks
- **Artistic Analysis**: Analyze images, audio, film, and text using various theoretical perspectives
- **Comparative Analysis**: Compare different media types and analyze them using any combination of frameworks

## Installation

1. Download the `deleometer` folder from this package
2. Copy the folder to your Obsidian vault's `.obsidian/plugins/` directory
3. Restart Obsidian
4. Enable the Deleometer plugin in Settings → Community plugins

## Usage

### Analyzing Journal Entries

1. Open a journal entry in Obsidian
2. Use the Command Palette (Ctrl/Cmd+P) to run "Deleometer: Analyze Journal Entry"
3. View the analysis results in the modal that appears

### Analyzing Artistic Content

1. Use the Command Palette (Ctrl/Cmd+P) to run "Deleometer: Analyze Artistic Content"
2. Select the file you want to analyze
3. Choose which theoretical frameworks to apply
4. View the analysis results

### Comparative Analysis

1. Use the Command Palette (Ctrl/Cmd+P) to run "Deleometer: Comparative Analysis"
2. Select multiple files to compare
3. Choose which theoretical frameworks to apply
4. View the comparative analysis results

## Theoretical Frameworks

Deleometer includes analysis through multiple theoretical lenses:

- Tacktical Methodology (Bufardeci)
- Freudian Psychoanalysis
- Lacanian Psychoanalysis
- Deleuzian Schizoanalysis
- Irigarayian Feminist Theory
- Jungian Analytical Psychology
