# The Deleometer Obsidian AI DeepSelf Discovery Journaling

A plugin for deep self-discovery journaling using AI. Use analysis history, and export options.

## Features

- Analyze journal entries using multiple theoretical frameworks
- Track emotional patterns over time
- Generate personalized insights
- Export analysis results
- OpenAI integration for enhanced analysis

## Installation

1. Download the latest release
2. Extract the zip file in your vault's `.obsidian/plugins/` folder
3. Enable the plugin in Obsidian settings

## Usage

1. Write a journal entry
2. Open the Deleometer analysis modal
3. Select the frameworks you want to use
4. Run the analysis
5. View and export the results

## Requirements

- Obsidian v0.15.0 or higher
- OpenAI API key (for premium features)
