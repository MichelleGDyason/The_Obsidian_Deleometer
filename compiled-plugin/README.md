# Deleometer Test Plugin

This is a simplified test version of the Deleometer plugin for Obsidian. It includes basic functionality to test the core features:

1. Journal Analysis
2. Artistic Analysis
3. Comparative Analysis

## Installation

1. Copy this folder to your Obsidian vault's `.obsidian/plugins/` directory
2. Restart Obsidian
3. Enable the plugin in Settings > Community plugins

## Testing

1. Open a note with some journal content
2. Use the Command Palette (Ctrl/Cmd+P) to run "Deleometer: Analyze Journal Entry"
3. Try the other commands to test different features

## Note

This is a simplified version for testing purposes only. The full version includes more advanced features and actual analysis capabilities.
